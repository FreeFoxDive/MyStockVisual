# 图表画线模式文档

> 面向 `visual` 主面板 K 线图的画线/标注功能：14 种工具、智能辅助（磁吸 / 自动支撑压力线 / 画线修正建议 / 未来预测延伸）、按 **登录用户 + 代码 + 周期** 存 SQLite，跨设备同步。
> 纯逻辑与集成层分离：算法在 `static/js/drawings.js`（UMD，Node 可测），交互与绘制在 `static/index.html`，存储在 `api/drawings.py` + `trades.py` 的 `chart_drawings` 表。

- 入口：工具栏「✏️ 画线」按钮 → 图表左缘悬浮工具面板（TradingView 风格竖排）。
- 数据按登录用户隔离：同一「代码+周期」每个账户各存一份，互不可见。
- 分时视图暂不支持画线（按钮点击会提示），K 线各周期（日/周/月/分钟）均可用。

## 2. 智能辅助（面板下部开关）

- **🧲 磁吸**：落子/拖拽时端点吸附 12px 内最近的 K 线开/高/低/收价，锚点更精准。
- **⚡ 自动建议线**：开启后对最近 150 根做 ZigZag（阈值 2%）摆动点拟合，支撑（低点连线）与压力（高点连线）各取触点最多（≥3 触点，收盘破位超过 1 根即否决）的一条，虚线标注「自动支撑/自动压力 · N触点」，自动向右延伸。自动线不持久化，数据刷新后重算。
- **画线修正建议**：趋势线/射线落子或拖拽后，在原锚点 ±4 根内搜索更优锚点（吸附该 bar 极值），触点评分更高时显示橙色虚线幽灵方案 + 「采纳/忽略」浮框，采纳即替换原画线。
- **未来预测延伸**：画线模式开启或存在延伸线/自动线时，图表右侧预留 8 根空白 bar（仅此时改变坐标轴范围，日常视图不受影响）；趋势线（迷你菜单开「延伸」）、射线、回归通道、自动线向右以虚线延伸并标注末端预测价。该区在各面板上以淡色带 + 「预测区」标注（`buildFutureZoneMarkArea`），否则没有分类标签的空白段会被误认为渲染缺口。

## 3. 交互与编辑

- **两段式画线**：点击落第一点 → 移动预览（虚线 + 端点圆圈）→ 点击定稿；Esc 或右键取消草稿。
- **单点工具悬停预览**：水平线/垂直线选中后，鼠标移动即给出一条跟手虚线（水平线同时挂价格签，与已落线的左缘价签同列避让）；坐标取磁吸后的点，预览停在哪点下去就画在哪；移出主图自动收掉。
- **水平线数值输入**：单击落线后**立刻在落点旁弹出数值框**（预填落点价并全选），输入时线实时跟随，Enter/确定/点别处 = 确认，Esc/取消 = 还原落点价；框内 ↑↓ 微调步长按价位量级取（<1 用 0.001 / <100 用 0.01 / 其余用 1）。已存在的水平线可选中后点迷你菜单「数值」，或直接双击该线改价（双击只认水平线，折线的「双击结束」不受影响）。改价可 Ctrl+Z 撤销。
- **选中与编辑**：选择工具点击画线 → 端点出现可拖拽手柄 + 迷你菜单（5 色圆点 / 线宽细粗 / 数值（水平线）/ 延伸开关（趋势线/斐波那契/回归/仓位盒/矩形）/ 删除）；Delete 键删除；Ctrl+Z 撤销（50 步，含新增/删除/移动/改价）。
- **悬停相交提示**：主图 tooltip 自动注入线型画线在该 bar 的**相交价位**（文字用画线颜色）与**相对该 bar 收盘价的偏离百分比**（(close−相交价)/|close|，正红负绿）。跨度语义与渲染一致：趋势线/通道取锚点区间，射线/回归（开延伸）向右含未来区，水平线全宽。
- **缩放兼容**：画线工具激活、或选择工具下**有选中画线**时禁用拖拽平移（选中那一刻图就不再跟着鼠标跑，交互预算留给这条线：拖手柄改端点、点菜单换色/监控；想拖拽平移先 Esc 或点空白处取消选中，也可以直接拖底部的缩放滑杆 —— 滑杆与滚轮都不受这个开关影响）；只有「选择工具 + 未选中」可拖拽平移，退出画线模式一律放开。缩放/刷新/主题切换后画线实时重投影。
- **显隐与清空**：👁 切换画线可见性（数据保留）；🗑 清空当前代码+周期的全部画线（confirm 确认，可撤销）。
- **控件随对象收起**：删除、Ctrl+Z 撤销、🗑 清空、👁 隐藏、换股/换周期之后，依附于「选中画线」的迷你菜单（换色/线宽/数值/延伸/🔔监控/删除）、监控输入框、数值输入框、修正建议浮框一并收起；👁 隐藏时同时清掉选区。**换选另一条线**时修正建议不销毁，而是改指向新选中的那条线（新对象不适配则清空收起），保证浮框与画布上的幽灵线始终属于当前选中对象；取消选中或删除时，修正建议（含幽灵线）与设置 UI 一起销毁。实现上是两道防线：定位函数在选中对象不存在时自行隐藏（`positionDrawMenu` 与 `positionSuggestBox` 同规矩，重绘每帧兜底），去除画线的路径统一走 `selectDrawing(null)` 这个唯一收尾口。

## 4. 数据模型与同步

- **锚点**：`{t, p, off}` —— `t`=K线日期字符串（过去锚点，按日期粘附，新增 bar 后不漂移）；`off`=距最后一根 bar 的偏移（未来锚点 `t=null`；亦作日期缺失时的兜底）；`p`=价格。停牌等缺失日期天然兼容。
- **隔离键**：`user_id + symbol + period`，`chart_drawings` 表 `UNIQUE` 约束 + 外键级联删除；每个登录用户各存一份，互不可见。
- **API**（`api/drawings.py`，登录 + CSRF 双提交）：
  - `GET /api/drawings?symbol=&period=` → `{drawings:[...]}`
  - `PUT /api/drawings` body `{symbol, period, drawings}` → 整体 upsert（≤500 条 / 512KB）
  - `DELETE /api/drawings?symbol=&period=`
- **前端同步**：切换代码/周期时拉取覆盖本地；每次编辑 800ms 防抖整体保存；请求由全局 fetch 包装器自动附加 CSRF 头。
- **趋势线监控字段**：`name`（监控名称，开启监控时前端强制填写）+ `monitor`（`{enabled, pct, adjust}`，跌破幅度 % 与复权口径）。监控配置随画线 JSON 一起保存，后端监控循环读取最新锚点评估，拖动/删除线天然跟随；`line_type` 仅 trend/ray/hline，周期仅 1d/1w/1M。`adjust` 记录开启监控时的图表复权方式（forward/hfq/none），后端用同一口径取 K 线算线值，避免前复权/不复权价格差异导致线值错位。触发状态（每条线每日一次）单独存 `trendline_monitor_state` 表，避免后端写画线 JSON 与前端整体覆盖互相踩踏。

## 5. 架构与实现要点

- **`static/js/drawings.js`（纯逻辑 UMD，无 DOM 依赖，Node 可测）**：日期索引映射与线性外推换算（支持未来 bar 越界）、Liang-Barsky 线段裁剪、命中测试、磁吸、ZigZag 摆动点、趋势线触点评分与修正寻优、最小二乘回归、斐波那契、`valueAt`（tooltip 相交价）、`setPointValue`（数值输入改价，非法值不动原对象）。
- **渲染层：独立 overlay canvas**（`#draw-overlay`，`pointer-events:none`，事件仍由 zrender 派发）。不使用 ECharts graphic——其增量合并对新增元素会静默丢弃；overlay 每帧 `clearRect` 全量重绘，确定性无状态。面板名称标签同样由 overlay 绘制。
- **未来空间**：仅按需把 category xAxis `max = len-1+8`，不改数据数组。**只作用于分类（日期）轴**：筹码叠加的 xAxis 是 value 轴（量纲 0..权重），一并写入会让筹码柱宽变亚像素、画线模式下整片消失（见 `applyFutureSlots` 的类型守卫）。
- **截图导出**：`saveChartImage()` 将 overlay 与 ECharts 画布手动合成后导出；侧栏可见时再把「基本信息/五档」按 `sidePanelShotModel()` 的行规格（与面板 HTML 同源：`infoPanelRows`/`depthPanelRows`）重绘到左侧留白区，导出图左侧因此不再是空白。回归测试见 `test/test_side_panel_shot_js.py`。

## 7. 已知限制

- 分时视图不支持画线（切回 K 线周期使用）。手机（≤640px）不提供画线入口，窄屏点选精度不够。
- 触屏无悬停预览：手指按下即落线并弹出数值框（悬停是鼠标概念），后续的跟手虚线只在鼠标工作。
- 文本标注暂不支持双击编辑既有文字（需删除重建）。
- 画线坐标以「日期字符串 + 相对偏移」锚定：分钟周期滚动出新 bar 后，超出数据窗口的旧锚点按相对偏移平移。
- 趋势线监控仅支持 日/周/月 K 与 趋势线/射线/水平线；分钟周期趋势线暂不参与监控（锚点解析复杂、场景少）。监控按线向右线性延伸的线值计算，即使画线未开「延伸」。
